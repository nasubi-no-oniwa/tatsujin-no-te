# 達人の手２

星・ハート・渦巻き・直線・花を、指でどれだけきれいに描けるかを競うゲーム。見本なし・一発勝負・7秒。

- 遊ぶ：https://nasubi-no-oniwa.github.io/tatsujin-no-te/2/
- 種目：星（ふちだけ）・ハート・渦巻き（2周以上）・直線・花（花びら5枚）。どれも一筆
- 採点：`sim.js`（星・ハート・花は、お手本の形を場所・大きさ・傾きを合わせて重ね、ずれの平均から点を出す。花はくびれの深さも描いた人に合わせる。渦巻きは「線と線の間が同じ幅」の渦巻きに、直線はまっすぐな線に合わせる）。同じ線なら点は必ず同じ
- 記録の線：120点を、紙の一辺を 0〜4095 に分けた場所で持つ（480文字）
- ランキング：達人の手と同じ Firebase ft-red の `tatsujin` の下（種目の名前で分かれる。ルールは一つ上の `database.rules.tatsujin.json`）
  - ランキングを読むときは、線から点を計算しなおして合わない記録は出さない（重いので `verify.js` の Worker で。確かめた記録は端末に覚えておく）
- 演出：95%以上でハンコといっしょに紙吹雪（pixelfx の confetti、`lib/pixelfx`、MIT）。画面の動きは GSAP（`lib/gsap.min.js`）
- 広告：結果画面とタイトル画面だけ（達人の手と同じ。`?noad=1` で広告なし）
- 試験：`node test/sim-test.mjs`（採点）
