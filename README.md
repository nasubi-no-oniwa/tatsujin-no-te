# 達人の手

〇・△・■・✖を、指でどれだけきれいに描けるかを競うゲーム。見本なし・一発勝負・7秒。

- 遊ぶ：https://nasubi-no-oniwa.github.io/tatsujin-no-te/
- 種目：〇・△・■（一筆）、✖（2本）。種目ごとに、精度がいい順のランキングがある
- 採点：`sim.js`（描いた線に、きれいな形を場所・大きさ・傾きを合わせて重ね、ずれの平均から点を出す。同じ線なら点は必ず同じ。ランキングを読むときも線から計算しなおして、合わない記録は出さない）
- 記録の線：72点（✖は36点＋36点）を、紙の一辺を 0〜4095 に分けた場所で持つ（288文字）
- ランキング：Firebase ft-red の `tatsujin` の下（`database.rules.tatsujin.json` を上げると自動で反映。鍵は `FT_RED_SERVICE_ACCOUNT`）
  - 100.000% の人は人数でまとめて表示、2位以下は上位100人
  - 名前を押すと、その人が描いた線を再生できる
- 広告：結果画面だけ（なすびのお庭の決まりどおり。`?noad=1` で広告なし）
- 試験：`node test/sim-test.mjs`（採点）、`test/rules-test.mjs`（ルール。GitHub の上で動く）
